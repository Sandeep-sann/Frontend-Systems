## 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/shopsphere-frontend.git
```

Go to project folder

```bash
cd shopsphere-frontend
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Open

```
http://localhost:5173
```
